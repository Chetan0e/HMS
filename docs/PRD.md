# Product Requirements Document (PRD) — HMS

## Product Purpose
HMS (Hostel & Stay Management) is a complete accommodation marketplace and property management platform designed to seamlessly connect accommodation seekers (students, travelers, interns, employees) with property owners and managers (PG, Hostel, Dormitory, Co-living owners).

## Key Features
- **Public & Discovery**: Hero search, property filters, map radius search, property comparison, detail view with real room availability.
- **Seeker Dashboard**: Bookings tracking, visit scheduling, saved properties, direct messaging.
- **Owner Portal**: Occupancy tracking, revenue charts, resident management, multi-step property creation wizard, maintenance request handler.
- **Admin Control**: Verification approval queue, platform user & property moderation, platform growth analytics.
